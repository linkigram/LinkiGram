# Дельта-обновления LinkiGram

Обновлятор скачивает разницу между **точными подписанными APK**, восстанавливает
новый APK и передаёт его обычному установщику Android. Данные приложения
сохраняются. Подтверждение установки и разрешение на установку из этого источника
по-прежнему нужны. Файлы установленного приложения напрямую не заменяются.

## Совместимость

- Поддержка клиента добавлена в 2.10.2. **Первый переход с 2.10.1 требует полного
  APK**: старый клиент не умеет применять патчи. Экономия доступна при следующих
  обновлениях на версии с этой поддержкой.
- Поддерживается монолитный APK. При split-установке используется полный APK.
- Совпасть должны SHA-256 и размер установленного APK, не только номер версии.
- Патч предлагается только при экономии не менее 15%. Если метаданных/подходящего
  патча нет, файл повреждён, не хватает места или проверка не прошла — скачивается
  обычный полный APK. Ошибка патча не должна блокировать обновление.
- Пауза сохраняет частично скачанный патч и продолжает его по HTTP Range.
  Восстановление после паузы начинается заново. После перезапуска процесса
  допускается переход на полный APK: release-метаданные дельты не сохраняются.
- Отмена/пауза не запускают fallback-загрузку. Отмена удаляет текущий патч;
  незавершённый восстановленный APK удаляется всегда. Патчи лежат во внутреннем
  кэше приложения, Android может очистить их.

## Проверки

До применения проверяются длина и SHA-256 патча, затем точный хеш базового APK.
Потоковый декодер ограничивает размеры, число команд и границы чтения/записи;
проверяет длину и SHA-256 результата. После восстановления обновлятор сверяет
хеш результата с manifest, пакет, versionName/versionCode и сертификат с
установленным приложением. Затем действуют обычные проверки обновлятора и
системного установщика Android. Manifest и патч загружаются только по HTTPS,
URL патча выбирается из assets **того же GitHub release**, а не из произвольного
адреса в manifest. Если GitHub публикует digest полного APK, он также сверяется.

Нужен запас места для нового APK, патча и установки. Патч не даёт уменьшения
размера установленного приложения.

## Подготовка релиза

`build.yml` после сборки загружает последний выпущенный ARM64 APK, создаёт патч
и manifest, проверяет восстановление production Java-декодером и сохраняет
отдельный артефакт **linkigram-delta**. Публикации релиза этот шаг не делает.
При недоступности предыдущего релиза optional-шаг может завершиться ошибкой;
полный APK в артефакте `linkigram-apk` остаётся доступным.

При публикации следующего релиза приложите:

1. Полный APK с именем `LinkiGram-<version>-arm64.apk`.
2. `linkigram-delta.json` из **той же CI-сборки**.
3. Все `.lgdelta`, указанные в этом manifest.

Не смешивайте manifest, патчи и APK разных сборок. Даже пересборка одного
коммита может изменить байты APK. Отсутствие assets просто отключит дельту.
Старый обновлятор игнорирует JSON/патчи и продолжает брать полный `.apk`.

Для нескольких баз вручную:

```sh
python3 Tools/make_apk_delta.py \
  --base old-release.apk --base another-release.apk \
  --target new-release.apk --apk-name LinkiGram-2.10.2-arm64.apk \
  --version 2.10.2 --version-code 202611279 --output-dir delta-assets
```

Не более 32 баз в manifest. Сами APK для баз также должны быть подходящей ABI.

## Формат LGDELTA1

Без JNI и дополнительных Android-зависимостей. Генератор использует блоки
16 КиБ и скользящий Adler-32 с побайтовым подтверждением совпадения. Декодер
читает команды COPY/DATA из gzip-потока, используя ограниченный буфер.

Заголовок: `LGDELTA1` (8 байт), длина базы и результата (big-endian int64),
SHA-256 базы и результата (по 32 сырых байта). Затем gzip-команды:

- `0`: END, должен совпасть с концом результата/потока;
- `1`: COPY, big-endian int64 offset + int32 length;
- `2`: DATA, big-endian int32 length + literal bytes.

Лимит APK — 512 МиБ; не более 1 000 000 команд. Отрицательные/нулевые длины,
выходы за пределы, неверные хеши и незавершённый поток отвергаются.

## Хост-проверки

```sh
python3 Tools/test_apk_delta.py
python3 Tools/test_delta_updater.py --json-jar /path/to/org-json.jar
python3 Tools/test_apk_delta.py --base old.apk --target new.apk
```

На реальной паре релизов 2.10 → 2.10.1 получен патч 30 412 844 байта вместо
108 702 799 байт (28%, экономия около 72%). Java-декодер восстановил APK с
совпадающим SHA-256. Это не гарантия такой же экономии для каждого релиза.
Изменение сжатых DEX и обфускация могут заметно увеличивать патч.

Хост-тесты HTTP/PackageManager используют фейки. Полный тест на Android:
скачивание из настоящего релиза, пауза/продолжение, восстановление, подтверждение
системного установщика и запуск обновлённого приложения — отдельная проверка.
